Verification & Terms of Service Endpoints

Verification URL:
/verify-user?user_id=YOUR_DISCORD_USER_ID
Terms of Service URL:
/terms-of-service.html
Note: This static site provides the endpoints Discord needs for verification. When Discord calls these URLs, it will get the required responses.

How to Use

  • Host these files on any static hosting (GitHub Pages, Netlify, Vercel, etc.)
  • Update Discord Developer Portal URLs to point to your hosted location
  • Enable Message Content Intent in Discord Developer Portal

File Structure

  • /verify-user - Returns JSON verification response
  • /terms-of-service.html - Terms of Service page
  • /privacy-policy.html - Privacy Policy page
